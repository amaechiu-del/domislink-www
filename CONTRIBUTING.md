# Contributing

Thanks for helping improve domislink-www! A few simple rules to keep things smooth:

- Branch from main: git checkout -b feat/your-feature
- Use clear commit messages: feat/ui: add hero section
- Open a PR and describe the change and why it matters
- Include screenshots or a short video for visual changes

Maintainers will review and request changes if necessary. Small, atomic PRs are easier to review.
