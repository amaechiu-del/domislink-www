# Good first issues to revitalize domislink-www

Below are five small tasks to help make the repository more contributor-friendly and deploy-ready. Each task includes acceptance criteria.

1) Add README.md improvements
- Description: Expand README to include project summary, preview steps, and deploy instructions.
- Acceptance: README.md contains Quick start, Deployment, Contributing, and Next steps sections.

2) Add LICENSE (MIT)
- Description: Add an MIT LICENSE file so contributors know the terms.
- Acceptance: LICENSE file present in repo root with the MIT text.

3) Add CONTRIBUTING.md
- Description: Provide contribution guidelines (branch naming, PR process, code style basics).
- Acceptance: CONTRIBUTING.md present with at least 3 contribution steps.

4) Add favicon and social preview image
- Description: Add favicon.ico and an Open Graph image and update index.html meta tags.
- Acceptance: favicon.ico in repo root and <meta property="og:image"> tag present in index.html.

5) Add basic HTML accessibility & validation check
- Description: Add a simple checklist or small script to validate index.html for common accessibility issues.
- Acceptance: A new file (e.g., ACCESSIBILITY.md or a CI check) added with basic validations.
